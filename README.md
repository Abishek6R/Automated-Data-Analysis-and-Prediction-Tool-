No-Code Machine Learning & Data Visualization Tool

Overview:
This project is a no-code, interactive platform that allows users to upload CSV files, explore data through automated visualizations, and make predictions using machine learning—all without writing any code. It is designed for data enthusiasts, students, and professionals who want actionable insights from their datasets quickly and easily.

Features:
Upload CSV files: Users can provide their own datasets without any coding knowledge.
Interactive data exploration: Automatically generates visualizations for numerical, categorical, text, and date-time data.
Automated preprocessing: Handles missing values, removes duplicates, encodes categorical variables, scales features, and handles outliers.
Smart model selection: Suggests appropriate machine learning models based on dataset characteristics and user input.
Train & evaluate models: Provides accuracy and performance metrics for selected models.
Predict new data: Users can input new rows to get predicted target variable values.
User-friendly interface: Everything can be done with simple questions and selections—no programming required.

Applications:
Quickly analyze any dataset without coding
Generate visual reports for presentations
Predict outcomes for business or academic datasets
Ideal for students, researchers, and business analysts
